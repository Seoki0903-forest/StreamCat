# StreamCat

PC(Windows)와 모바일(Android)을 USB 또는 로컬 Wi-Fi로 연결해 사용하는 **커스텀 매크로 패드 & 볼륨 믹서** 앱 **StreamCat**의 공식 다운로드 및 정책 저장소입니다.

Turn your smartphone into a fast, customizable PC macro pad and Windows volume mixer over USB or local Wi-Fi (QR scan & auto-discovery).

## 모바일 연결 방법 / Connect your Android device

1. Windows PC에 위 **StreamCat PC 설치 파일**을 설치하고 실행합니다. (트레이 또는 창에서 연결 QR 코드 확인 가능)
2. Android 기기에서 StreamCat 앱을 실행합니다. (**Google Play 내부 테스트** 배포)
3. **USB 유선 연결** 또는 같은 공유기 환경의 **로컬 Wi-Fi (QR 코드 스캔 / 주소 자동 탐색)**로 연결합니다.
